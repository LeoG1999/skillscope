# SkillScope

接真实模型的 agent skill 行为评审工具。没有预设场景：skill 由用户粘贴，世界由工具层生成后冻结，
情况集从真实使用中累积。

## 运行

    export DEEPSEEK_API_KEY=sk-...
    python3 server.py                  # http://127.0.0.1:8000

只依赖 Python 标准库。`PORT=8738` 换端口，`SKILLSCOPE_MODEL=deepseek-v4-pro` 换模型。

## 它怎么工作

1. **粘贴 skill** — 任意格式的 SKILL.md。模型解析出编号指令、工具清单、配置，并标出会产生
   副作用的工具（强制 dry-run）。
2. **描述任务** — 工具层依据工具签名**和指令实际会用到的字段**生成一个世界，然后**冻结**。
   之后所有重跑都重放这个快照，配对执行才严格可比。
3. **执行** — 同一快照跑 k 次，得到工作流、事实字段与跨次分布。首次执行确定 `fact_schema`，
   后续沿用，保证逐字段可比。
4. **探测** — 侧边栏点任意一条指令：
   - **删除** 该指令后重跑
   - **反转** 该指令（模型改写成相反含义）后重跑
   - **扰动输入** 改动快照里一个值后重跑
5. **表达预期** — 说出你要的行为，系统提出 2–3 条不同严格度的判据，**立刻在已有执行上试判**，
   你选一条，它成为情况集里的一条。
6. **修改与对比** — 起草修改，在全部情况上跑修改前后，冲突项会被标出，发布闸门据此放行或拦截。

## 诊断表

删除与反转合起来才能定性。这解决了单靠删除的系统性低报：

| 删除后 | 反转后 | 判定 |
|---|---|---|
| 无变化 | 有变化 | 指令有效，但与模型固有倾向同向 |
| 无变化 | 无变化 | 指令未被遵循 |
| 有变化 | 有变化 | 指令在控制该行为 |
| 有变化 | 无变化 | 结论不一致，提高重复次数 |

基线或探测的主导行为占比低于 0.6 时，一律标为"证据不足"，不给结论。

## 已验证

`deepseek-v4-flash`，快照与执行各约 4–5 秒（k=3）：

- 粘贴解析：6 条指令、3 个工具，`booking.rebook` 正确识别为副作用工具
- `fact_schema` 自动导出：`selected_flight / arrival_time / confirmation_requested` …
- 指令 3「选最低价」：删除无变化、反转有变化 → **与模型倾向同向**
- 指令 1「读日历」：删除无变化、反转无变化 → **未被遵循**

## 修复范围的三档

记录预期时必须选一档，对比时分别判定：

| 档位 | 判定依据 | 未达成时 |
|---|---|---|
| 需要修改 | 判据；无判据则看行为是否改变 | 未达成预期 |
| 保持现状 | 有判据用判据，否则比行为签名 | 该项已被破坏 |
| 暂不决定 | 行为**不应**变化 | 已被自行决定 |

说出一条「需要修改」后，系统会提出两条可能被牵连的相邻情况请求表态，其中一条**对起草模型保密**，
用于修改完成后的独立检验。

## 评审出口

发布 / 重新起草 / 补充执行 / 暂缓，四个出口都写入评审记录（决定、理由、时间、skill 与候选哈希、
当时的情况集）。重新起草会把上一轮的对比结果一并交给起草模型，避免重复同一个错误。

指令可由用户直接编辑，保存为候选版本并标记 `author: owner`。

## 多 skill 与评审包

侧边栏可切换、重命名、删除 skill。快照、执行、情况集、探测**按 skill 隔离**，切换互不干扰。

导出得到一个评审包（`skillscope/1`）：skill 全文与版本、全部快照、执行记录、情况与判据、
探测与结论。这正是稿子附录要求的 release record，也可直接作为实验原始数据。导入后作为
一个新的 skill 恢复，附带全部历史。

## 实现要点

- **推理必须关闭**（`thinking:{"type":"disabled"}`）。开启时思维链会吃光 max_tokens 导致空输出，
  单次执行从 4 秒变成 60 秒以上；关闭后更贴合"逐字执行指令"。
- **行为签名只比主决策键**。模型的 JSON 类型会抖动（`false` / `"false"` / 自由文本），
  全字段比较会把稳定行为误判成不稳定。
- **快照生成必须看到指令**。否则世界里可能缺少指令引用的字段（例如没有 price，
  "选最低价"就无从执行），行为随即变成随机。
